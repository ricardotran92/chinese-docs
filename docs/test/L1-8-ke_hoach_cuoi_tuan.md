# BÀI KIỂM TRA

## L1-8 Kế hoạch cuối tuần

### Overview (Tổng quan bài kiểm tra)

- **Loại bài học:** Bài kiểm tra (Test)
- **Thời lượng:** 3–5 phút
- **Số câu hỏi:** 15
- **Nội dung chính:** Kiểm tra kiến thức về từ vựng, mẫu câu và cách diễn đạt kế hoạch, hoạt động vào cuối tuần

> **Lưu ý:** Bạn đã hoàn thành các bài học chính! Hãy làm bài kiểm tra để xem bạn nắm vững kiến thức đến đâu nhé.
