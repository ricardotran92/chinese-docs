# BÀI KIỂM TRA

## L1-7 Sinh nhật (Birthday)

### Overview (Tổng quan bài kiểm tra)

- **Loại bài học:** Bài kiểm tra (Test)
- **Thời lượng:** 3–6 phút
- **Số câu hỏi:** 16
- **Nội dung chính:** Kiểm tra kiến thức về từ vựng (số đếm 6-10, tháng, ngày, sinh nhật), ngữ pháp (几, 呢, 名词谓语句) và mẫu câu hỏi về ngày tháng, sinh nhật.

> **Lưu ý:** Bạn đã hoàn thành các bài học chính! Hãy làm bài kiểm tra để xem bạn nắm vững kiến thức đến đâu nhé.
