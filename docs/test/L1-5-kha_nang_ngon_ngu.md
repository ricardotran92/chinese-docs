# BÀI KIỂM TRA

## L1-5 Khả năng ngôn ngữ (Language Ability)

### Overview (Tổng quan bài kiểm tra)

- **Loại bài học:** Bài kiểm tra (Test)
- **Thời lượng:** 2–4 phút
- **Số câu hỏi:** 12
- **Nội dung chính:** Kiểm tra kiến thức về từ vựng, ngữ pháp và mẫu câu đã học trong bài L1-5

> **Lưu ý:** Bạn đã hoàn thành các bài học chính! Hãy làm bài kiểm tra để xem bạn nắm vững kiến thức đến đâu nhé.

### Câu 2: Chọn bản dịch đúng

**Câu hỏi:** <button onclick="speakNormal('我们说英语。')"><span class="hanzi">**我们说英语。**</span></button> (Wǒmen shuō Yīngyǔ.)

| Lựa chọn | Đúng/Sai |
| :--- | :--- |
| Chúng tôi nói tiếng Anh. | ✅ |
| Anh ấy không biết nói tiếng Anh. | ❌ |
| Tôi biết nói tiếng Trung. | ❌ |

**Đáp án đúng:** *Chúng tôi nói tiếng Anh.*

---

### Câu 3: Chọn bản dịch đúng

**Câu hỏi:** <button onclick="speakNormal('谁会说汉语？')"><span class="hanzi">**谁会说汉语？**</span></button> (Shéi huì shuō Hànyǔ?)

| Lựa chọn | Đúng/Sai |
| :--- | :--- |
| Ai biết nói tiếng Anh? | ❌ |
| Ai biết nói tiếng Trung? | ✅ |
| Câu là ai? | ❌ |

**Đáp án đúng:** *Ai biết nói tiếng Trung?*

---

### Câu 4: Chọn từ điền vào chỗ trống

**Hội thoại:**

| Tiếng Trung | Pinyin | Tiếng Việt |
| :--- | :--- | :--- |
| A: 你是 **____** 国人? | A: Nǐ shì **nǎ** guó rén? | A: Bạn là người nước nào? |
| B: 我 **____** 中国人。 | B: Wǒ **shì** Zhōngguó rén. | B: Tôi là người Trung Quốc. |

**Đáp án đúng:**

- A: <button onclick="speakNormal('你是哪国人？')"><span class="hanzi">**你是哪国人？**</span></button>
- B: <button onclick="speakNormal('我是中国人。')"><span class="hanzi">**我是中国人。**</span></button>

### Câu 5: Chọn câu trả lời phù hợp với câu hỏi

**Câu hỏi:** <button onclick="speakNormal('她是谁？')"><span class="hanzi">**她是谁？**</span></button> (Tā shì shéi?) – *Cô ấy là ai?*

| Lựa chọn | Đúng/Sai |
| :--- | :--- |
| <button onclick="speakNormal('她不是老师。')"><span class="hanzi">**她不是老师。**</span></button> | ❌ |
| <button onclick="speakNormal('她是我朋友。')"><span class="hanzi">**她是我朋友。**</span></button> | ✅ |
| <button onclick="speakNormal('他是中国人。')"><span class="hanzi">**他是中国人。**</span></button> | ❌ |

**Đáp án đúng:** <button onclick="speakNormal('她是我朋友。')"><span class="hanzi">**她是我朋友。**</span></button>
